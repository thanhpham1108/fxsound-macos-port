# macOS icon

`FxSoundMac.png` and `FxSoundMac.icns` are generated from `generate_icon.swift`. The artwork is an original multicolour waveform for this unofficial macOS port. It does not contain the FxSound five-bar logo.

On a Mac with Xcode Command Line Tools, regenerate both assets with:

```sh
sh macos/assets/generate_icon.sh
```
